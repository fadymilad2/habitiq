# 🚀 HabitIQ: AI-Powered Habit Tracker

Welcome to **HabitIQ**, a premium, AI-driven, and highly optimized habit-tracking application built with Flutter. 

Building a habit tracker is common, but engineering a smart, reliable, and cost-effective product is the real challenge. HabitIQ focuses on delivering a smooth user experience, offline accessibility, strict backend cost optimization, and an intelligent AI companion that actually cares about your mood!

---

## ✨ Core Features

* 🤖 **Friendly AI Companion:** An integrated smart assistant that adapts to your mood. It acts as a supportive friend, offering personalized and uplifting feedback to keep your motivation high.
* ⚡ **Offline-First (Hive):** Instantaneous local storage. Add, edit, and complete habits blazingly fast without needing an active internet connection.
* ☁️ **Optimized Cloud Sync (Firestore):** A custom batch-write sync strategy. It syncs data in the background at the start of a new day or manually via a custom animated UI, drastically reducing Firestore reads/writes to save costs.
* 🔐 **Seamless Authentication:** Secured with Firebase Auth (Email/Password, Google Sign-In, and Anonymous Guest mode).
* 🔔 **Zero-Cost Local Notifications:** Daily on-device reminders using `flutter_local_notifications` and `timezone`, completely bypassing the need for paid cloud functions.
* 🎨 **Premium UI/UX:** A stunning Dark Theme featuring Glassmorphism, smooth `RotationTransition` animations, and a highly responsive design.

---

## 🛠️ Tech Stack & Architecture

* **Framework:** Flutter / Dart
* **State Management:** Cubit (Bloc Pattern)
* **Local Storage:** Hive
* **Backend as a Service (BaaS):** Firebase (Auth & Cloud Firestore)
* **Architecture:** Clean Architecture principles with feature-driven folder structure.
